# Case study — Pricing page (marketing)

Sources: [Desisle SaaS pricing page guide](https://www.desisle.com/resources/saas-pricing-page-design-guide).

## Job

Help a visitor pick a plan in under ~30 seconds and start trial/checkout — or talk to sales for enterprise.

## Default anatomy (common 11 elements)

1. Headline + subcopy (who it’s for)
2. **Monthly / annual toggle** (annual savings called out)
3. **2–4 tier cards** — name, price, blurb, feature bullets, CTA
4. **Recommended tier** highlight
5. **Feature comparison table**
6. **FAQ** (8–12 questions)
7. Trust signals (logos, quotes, compliance badges)
8. Enterprise / custom CTA
9. Risk reversal (trial, no card, guarantee)
10. Clear CTA per tier
11. Secondary content below fold (comparisons, calculators — optional)

## Content that should appear on each tier card

- Tier name
- Price + billing interval
- 3–7 differentiating features (not the whole product)
- Primary CTA (“Start free”, “Get Pro”)
- Who it’s for (one line)

## Defaults

- 3 tiers is the common sweet spot; 4th often = Enterprise separate
- Highlight one recommended plan
- Free/trial CTA without forcing “Contact sales” on every tier

## Anti-patterns

- “Contact sales” on all tiers
- Unclear monthly vs annual
- Feature lists identical across tiers
- No FAQ for billing/tax/refunds

## Checklist

- [ ] Tier differences scannable in 30s
- [ ] Interval toggle obvious
- [ ] Comparison table + FAQ present
- [ ] Every tier has a CTA; enterprise path available without blocking self-serve
