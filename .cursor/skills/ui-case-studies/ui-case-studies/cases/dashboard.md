# Case study — Dashboard / home

## Job

Answer “What’s happening / what should I do next?” in one glance for the signed-in user.

## Default content (pick what fits)

1. **Greeting / context** — name, workspace, last activity (light)
2. **Primary CTA** — the main create/continue action
3. **Key metrics** — 3–6 numbers max, with period (today / 7d)
4. **Work queue** — recent items, assigned to me, needs attention
5. **Secondary modules** — tips, setup checklist (dismissible), integrations status

## Defaults

- First-run: setup checklist instead of empty charts
- Metrics: show “—” or empty state, not fake zeros that mislead
- Personalize to role when roles exist (admin vs member)

## Anti-patterns

- Metric soup (10+ cards with no hierarchy)
- Charts with no units or time range
- Marketing blog embed as the only home content
- Blocking onboarding modal every visit
