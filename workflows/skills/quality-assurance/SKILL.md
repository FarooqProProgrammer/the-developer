# Quality Assurance

Map acceptance criteria to existing unit, integration and functional checks. Exercise permissions, edge cases and failure behavior. Run relevant commands and preserve exit codes. Record passed, failed, skipped and unrun outcomes separately. A PID, open port, formatter or zero-test run does not establish readiness. Report reproducible defects without hiding failures.

## Completion evidence
Report changed files, commands actually executed, outcomes, remaining limitations and next owner. Follow project instructions and `.specs/constitution.md`.
