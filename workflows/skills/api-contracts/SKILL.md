# Api Contracts

Record methods, paths, headers, request/response schemas, status codes, pagination and error envelopes. Define permission requirements and nullable fields explicitly. Link each contract to acceptance criteria. Use the project schema tool or OpenAPI when already adopted. Verify frontend and backend against the same contract; document incompatible changes.

## Completion evidence
Report changed files, commands actually executed, outcomes, remaining limitations and next owner. Follow project instructions and `.specs/constitution.md`.
