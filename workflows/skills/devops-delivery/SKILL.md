# Devops Delivery

Inspect version pins, lockfiles and CI. Use frozen dependency installation where available. Record required services and variable names without values. Validate a real build and health request. Define migration order, rollback, logs and resource limits. Treat production deployment as a separately authorized action; do not infer permission from local build success.

## Completion evidence
Report changed files, commands actually executed, outcomes, remaining limitations and next owner. Follow project instructions and `.specs/constitution.md`.
