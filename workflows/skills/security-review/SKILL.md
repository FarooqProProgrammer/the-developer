# Security Review

Trace untrusted inputs through APIs, data stores and outbound requests. Review object-level access, session handling, injection risks, secret exposure and dependencies. Prefer project security tooling. Rank findings by impact and evidence. Never claim a complete security audit from a small checklist; verify fixes against the original exploit condition.

## Completion evidence
Report changed files, commands actually executed, outcomes, remaining limitations and next owner. Follow project instructions and `.specs/constitution.md`.
